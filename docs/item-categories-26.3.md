# Items added since Minecraft Java 26.1

The complete item-asset lists in the official Mojang 26.1 and 26.3 client JARs were compared. All 1,506 item definitions from 26.1 remain in 26.3; 26.3 contains 1,658 definitions, giving 152 additions. Every addition has one explicit category assignment. Color variants are included individually.

Content references: [Java 26.2 release notes](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-2) and [Java 26.3 release notes](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3). The actual ID list was taken from the game files, including IDs such as new explorer maps that are not obtainable in the creative inventory.

The comparison is preserved as an independent test fixture, and the build checks complete category coverage. Runtime additions are merged into the original category sets during client initialization.
